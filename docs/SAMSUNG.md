# Samsung background-session setup

Samsung devices apply additional background limits beyond standard Android behavior. For a long inference session:

1. Open LLMHotspot → Settings → **Allow uninterrupted sessions** and approve the system prompt.
2. Open Settings → Battery → Background usage limits → Never auto sleeping apps, then add LLMHotspot.
3. Open the Recents screen, tap the LLMHotspot icon, and choose **Keep open** when that option is available.
4. Keep the persistent “LLM Hotspot” notification enabled.

Menu labels vary by One UI version. The app still enforces its configured battery and temperature stops after exemption.
